# Contributing

This is an infrastructure-only public repository.

Pull requests may add source adapters, storage backends, health monitoring,
plugin-host reliability, packaging, deployment templates, and strategy-neutral
tests. They must not add market-selection rules, predictive features, parameter
values, decision thresholds, derived research results, or execution logic.

Private plugins must remain in an ignored local/VPS directory or a separate
private package. Review both the proposed tree and commit history before push.
